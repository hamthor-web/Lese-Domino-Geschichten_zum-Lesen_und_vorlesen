# Geschichtenbuch – Entwicklungsstand 26.11.2026
Bestätigt: eigenständiges wiederverwendbares Buchmodul für Lesegeschichten, keine Änderungen an Eiche oder Silvana. Hochformat eine Seite, Querformat Doppelseite. Dicke Papierstapel, räumliches Blättern; Navigation über untere linke und rechte Seitenecken statt separater Vor/Zurück-Buttons (Testentscheidung). Unabhängige Buch- und Schriftgröße, Inhalte erreichbar. Gestaltung und Entscheidungen ausschließlich hier auf GitHub dokumentieren.
Test 1: story-book.js als Web Component, index.html mit zwölf Platzhalterseiten. Keine Integration, kein Release. Noch offen: echte Geräteprüfung, verbesserte Papierwölbung und dynamische Stapeldicke, Umblättergeräusch, Fortschrittsspeicherung, Doppelseiten-Sonderlayout, Integration nach Freigabe. CSS-3D-Prototyp nutzt starre Seitenrotation, keine echte Papierkrümmung.
